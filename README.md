# Análisis de Despachos de una PyME
Los registros analizados provienen de despachos.csv
## Datos Analizados
- Identificador del pedido (`order_id`)
- Comuna de entrega
- Despachos totales
- Estado del envío (Entregado / En camino) 

## Resultados Principales
| Comuna | Despachos | Entregado | En camino |
| ------ | --------- | --------- | --------- |
| Maipú | 120 | 118 | 2 |
| Ñuñoa | 98 | 95 | 3
| Puente Alto | 85 | 85 | 0 |
| Huechuraba | 115 | 110 | 5 |

Los datos están en [despachos.csv](datos/despachos.csv).
